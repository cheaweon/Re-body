WHY RE:BODY?

건강관리는
왜 어려울까요?

건강관리는 꾸준한 기록과 데이터 확인이 필요하지만, 직접 입력하고 각각의 데이터를 따로 확인해야 하는 불편함이 있습니다.

😓

식단 기록의 번거로움

먹은 음식을 하나씩 검색하고 영양정보를 직접 입력해야 합니다.

📊

흩어진 건강 데이터

식단·활동·수면 등의 데이터가 서로 분리되어 관리됩니다.

💬

데이터는 있지만 활용이 어려움

단순한 숫자와 기록만으로는 현재 나에게 필요한 행동을 파악하기 어렵습니다.

그래서 Re:Body는

기록의 번거로움을 줄이고, 건강 데이터를 연결하고, AI를 통해 개인 맞춤형 피드백으로 연결합니다.
CORE FEATURES

Re:Body의 핵심 기능

하나의 앱에서 건강 데이터를 기록하고, 통계로 확인하고, AI를 통해 개인에게 맞는 피드백까지 연결합니다.

01 / 04
INTEGRATED HEALTHCARE

식단만 관리하지 않습니다.
건강 데이터를 함께 봅니다.

식단·활동량·수면·수분을 하나의 서비스에서 기록하고 관리합니다. 각각의 데이터를 따로 확인하는 것이 아니라 하나의 흐름으로 관리할 수 있습니다.

식단 활동량 수면 수분 Google Fit
02 / 04
AI FOOD ANALYSIS

여러 음식을 분석합니다.

📷 사진 → YOLO 탐지 → YOLO 분류 → 영양정보

03 / 04
DATA & STATISTICS

기록을 쌓고
패턴을 확인합니다.

캘린더와 기간별 그래프를 통해 칼로리·탄수화물·단백질·지방·활동량·수면 등의 변화를 시각적으로 확인합니다.

→ 기록을 단순 저장하는 것이 아니라 변화와 패턴을 확인할 수 있도록 구성했습니다.

Flutter
FRONTEND

Dart 기반 모바일 앱 개발. 식단·활동·수면·그래프·캘린더·챗봇 등 사용자 화면을 구성합니다.

Flask
BACKEND

REST API 서버. 모바일 앱의 요청을 처리하고 AI 및 데이터베이스와 연결합니다.

YOLO
COMPUTER VISION

MySQL
DATABASE

Google Fit

Groq API
LLM

OUR DIRECTION

우리가 만들고 싶었던 것은
‘기록 앱’이 아닙니다.

기록된 데이터를 다시 활용하여 사용자의 생활습관 개선으로 연결하는 것을 목표로 했습니다.

기존 기록 방식

먹은 음식 입력 ↓ 숫자 확인 ↓ 기록 종료

Re:Body

기록 ↓ 데이터 통합 ↓ 통계·패턴 확인 ↓ AI 분석 ↓ 맞춤형 피드백
IMPLEMENTATION RESULT

아이디어를 실제 기능으로
구현했습니다.

01

AI 음식 분석

음식 사진 입력부터 탐지·분류 및 영양정보 확인까지 구현했습니다.

02

건강 데이터 관리

식단·활동·수면·수분 데이터를 하나의 서비스에서 기록하고 관리합니다.

03

통계·시각화

캘린더와 그래프를 통해 날짜별 기록과 기간별 변화를 확인합니다.

04

맞춤형 건강 피드백

섭취량과 활동량 등의 데이터를 기반으로 현재 상태에 맞는 피드백을 제공합니다.

05

AI 챗봇

사용자의 건강 데이터를 바탕으로 식단·활동·수면 관련 질문에 답변합니다.

06

외부 데이터 연동

Google Fit의 활동 데이터를 활용하여 건강관리 데이터의 범위를 확장했습니다.

LIMITATIONS

현재의 한계도
